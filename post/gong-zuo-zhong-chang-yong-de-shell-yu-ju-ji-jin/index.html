工作中常用的Shell语句集锦

2019-07-05 2 分钟阅读
Shell
<p>工作中用到Shell脚本一般不是太复杂，会有一些即时的统计计数、文件查看。总结一些语句，方便在自己遗忘时查看。</p> <!--more--> <ul> <li>查看文件占用空间大小</li> </ul> <pre><code>du -sh * | sort -rh #按从大到小的顺序排 du -sh * | sort -h #按从小到大的顺序排 </code></pre> <ul> <li>统计文件行数</li> </ul> <pre><code>wc -l filename </code></pre> <ul> <li>删除文件的1-7行，在原文件上修改</li> </ul> <pre><code>sed -i '1,7d' filename </code></pre> <ul> <li>查看文件的某一行并提取该行的最后一列，如第1845行</li> </ul> <pre><code>sed -n 1845p filename cat filename | awk 'NR==1845' | awk '{print $NF}' </code></pre> <ul> <li>查看文件的3000行到4000行</li> </ul> <pre><code>cat filename | head -n 4000 | tail -n 1000 </code></pre> <ul> <li>提取文件中某一列符合要求的行</li> </ul> <pre><code>cat filename | awk '$4 == &quot;n37&quot; {print}' </code></pre> <ul> <li>提取文件中某几列符合要求的行到新文件</li> </ul> <pre><code>cat filename | awk '{if($2 == 99)print}{if($2 == 163)print}' | awk '{print $3&quot;\t&quot;$4&quot;\t&quot;$4+38}' &gt; newfile </code></pre> <ul> <li>计算文件最后一列的和并输出</li> </ul> <pre><code>awk '{sum +=$NF}; END {print sum}' filename </code></pre> <ul> <li>计算文件每行的和并输出为一个列向量</li> </ul> <pre><code>awk '{for (i=1; i&lt;= NF; i++) sum += $i;print sum;sum=0;}' filename &gt; newfile </code></pre> <ul> <li>删去文件1的最后几行使其与文件2行数一致，存为文件3</li> </ul> <pre><code>long=$(sed -n ' $=' filename1) short=$(sed -n ' $=' filename2) sed $ (( $short+1)), ${long}d filename1 &gt; filename3 </code></pre> <ul> <li>删除文件的后3行</li> </ul> <pre><code>tac filename | sed 1,3d | tac &gt; newfile sed ' $d' filename | sed ' $d' |sed ' $d' &gt; newfile </code></pre> <ul> <li>计算文件第一列有哪些不同值并输出/对文件排序去重后输出为新文件</li> </ul> <pre><code>cat filename | awk '{print $1}' | sort | uniq -c sort -k1,1 -k2,2n filename | uniq &gt; newfile </code></pre> <ul> <li>输出文件第一列的最大值/最小值</li> </ul> <pre><code>cat filename | awk 'NR == 1{max=$1;next}{max=max&gt;$1?max:$1}END{print max}' cat filename | awk 'NR == 1{min=$1;next}{min=min&lt;$1?min:$1}END{print min}' </code></pre> <ul> <li>批量清除任务</li> </ul> <pre><code>ps -ef | grep taskscriptname | cut -c9-15 | xargs kill -9 </code></pre> <ul> <li>提取含关键字的行相关命令</li> </ul> <pre><code>#提取含real的行输出其第二列，每三个写入一行中 grep -n -E 'real' nohup.log | awk '{print $2}' | awk '{if(NR%3!=0)ORS=&quot; &quot;;else ORS=&quot;\n&quot;}1' &gt; time3.log </code></pre>
